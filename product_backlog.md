# Product Backlog - Habit Tracker App

This backlog contains all user stories prioritized and grouped by application feature.

---

# High Priority

## Login & Registration

### Account Registration
**Description:** Allow users to register with their name, username, age, and country to create an account.

**Labels:** enhancement, priority: high

### Account Login
**Description:** Allow users to log in using their username and password.

**Labels:** enhancement, priority: high

### Error Feedback on Login
**Description:** Display an error message when invalid login credentials are entered.

**Labels:** enhancement, priority: high

---

## Home Page

### View Welcome Message
**Description:** Display a personalized welcome message containing the user's name.

**Labels:** enhancement, priority: high

### Display Weekly Progress
**Description:** Show the user's daily progress for each habit on the homepage.

**Labels:** enhancement, priority: high

### View Completed Habits
**Description:** Display completed habits in a dedicated section on the homepage.

**Labels:** enhancement, priority: high

---

## Habits

### Add a New Habit
**Description:** Allow users to create and manage new habits.

**Labels:** enhancement, priority: high

### Delete a Habit
**Description:** Allow users to remove habits that are no longer needed.

**Labels:** enhancement, priority: high

---

## Menu

### Sign Out From Menu
**Description:** Allow users to securely sign out of the application.

**Labels:** enhancement, priority: high

---
